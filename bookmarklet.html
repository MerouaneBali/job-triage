Dump LinkedIn Jobs (live DOM)

A bookmarklet is a bookmark that runs a tiny script in the current tab. This one downloads the page HTML you already see — same idea as Save Page As, one click, unique timestamped filename.

Optional: Save Page As often works fine too. Use this when you want a guaranteed live-DOM dump and non-colliding names.

Drag this to your bookmarks bar:

Dump LinkedIn Jobs HTML
  1. Open LinkedIn Jobs search results and scroll until cards you care about are loaded.
  2. Click the bookmarklet → an .html file downloads to your browser’s Downloads folder (bookmarklets cannot write into data/dumps/ directly).
  3. Move it into data/dumps/ and run:
    npm run parse
  4. Fetch descriptions (guest browser):
    npm run fetch-details -- data/stage1/your-file.json
  5. Triage:
    npm run preview → http://127.0.0.1:4173

Safety: This bookmarklet is client-side only — reads the current page and triggers a download. Stage-2 fetch uses a separate ephemeral Playwright window; do not log into LinkedIn there.

Personal offline triage only. Don’t automate Easy Apply or use your logged-in profile for scraping.
